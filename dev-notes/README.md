# dev-notes

本目录存放 `bumplist-alloc` 的设计、技术决策与实验记录。正文以中文为主，
涉及代码标识符时保留原文。

## 文件命名

`[主题]-YYYYMMDD-HHMM.md`，其中日期时间为本地时间，例如：

- `bumplist-20261116-1900.md`

主题尽量短，多个词用短横线分隔。每篇文档应在开头注明状态，例如：设计草案、
待讨论、已确认、已实施、已废弃。

## 写作约定

- 先写背景与约束，再写方案；方案要能回答“为什么不是另一种做法”。
- 多轮讨论后及时把最终结论与因果链补进文档，过时讨论可以删除或压缩。
- 涉及 `unsafe`、生命周期、并发与内存布局的结论，必须写清不变量与安全论证。
